Feature 1: Add Student
🔹 Mistake 1: List Scope Issue

Mistake:
Created the students list inside the function.

Problem:
Each function call created a new empty list → previous data was lost.

Learning:
Data that must persist across function calls should be defined outside the function.

🔹 Mistake 2: Incorrect append() Usage

Mistake:
Used append(1) while adding the student.

Problem:
Inserted an unnecessary number instead of the student record.

Learning:
append() should receive the actual data to store → here, the student record.

🔹 Mistake 3: Assignment Inside List

Mistake:
Tried marks = [] inside list.

Problem:
= cannot be used inside expressions.
== is comparison, not assignment.

Why := worked:
Allows assignment inside expressions.

Learning:

= → assignment

== → comparison

:= → assignment inside expressions

Helper Function (Internal) -
